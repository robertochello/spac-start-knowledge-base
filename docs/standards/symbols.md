# Standard simboli

## Obiettivo

Definire regole operative per creare, validare e riutilizzare simboli custom in SPAC Start.

## Regole

- Un simbolo deve avere una funzione chiara.
- Un simbolo deve essere testato in un progetto prova.
- Un simbolo Madre deve essere identificabile tramite attributi coerenti.
- Un simbolo Figlia deve avere relazione chiara con il componente principale.
- Una macro deve essere composta da elementi già validati.

## Simbolo Madre

Convenzione:

```text
PRES = M
```

## Simbolo Figlia

Usare simboli Figlia per elementi associati al componente principale.

Esempi concettuali:

- contatti;
- bobine;
- accessori;
- elementi funzionali collegati.

## Macro

Una macro deve essere considerata un insieme riutilizzabile, non un modo per nascondere simboli non validati.

## Validazione

Prima del riuso, applicare la checklist di validazione simbolo.
