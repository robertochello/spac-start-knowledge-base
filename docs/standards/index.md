# Standards

Questa sezione raccoglie gli standard operativi della knowledge base.

## Standard disponibili

| Standard | Scopo |
|---|---|
| [Standard simboli](symbols.md) | Regole per simboli custom, Madre, Figlia e macro |
| [Standard CAD](cad.md) | Regole per layer, geometrie e DWG |
| [Standard materiali](materials.md) | Regole per materiali, archivi custom e associazione ai simboli |

## Regola generale

Uno standard definisce come lavorare. Una procedura definisce i passi operativi. Un caso pratico documenta un problema reale o ricorrente.
