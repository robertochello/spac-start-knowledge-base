## Se stai facendo un nuovo progetto

Segui questo ordine:

1. [Prepara il progetto](16-project-template.md).
2. [Controlla la libreria custom](15-custom-library.md).
3. Scegli [Unifilare](17-unifilare.md) oppure [Multifilare](09-multifilare.md).
4. Quando ti serve un comando preciso, apri [Comandi e click esatti](command-reference.md).

## Regola della guida

Le procedure devono essere semplici:

```text
1. Clicca qui
2. Imposta questo valore
3. Premi questo pulsante
4. Controlla che succeda questo
```

Se il nome esatto di un comando non è ancora noto, viene scritto **Da verificare** invece di inventarlo.
