# Template progetto

Questa sezione definisce la base operativa per creare un progetto SPAC riutilizzabile per schemi unifilari e multifilari.

## Obiettivo

Creare una struttura progetto ordinata prima di iniziare lo sviluppo degli schemi.

Il template deve essere una base comune. Le differenze tra unifilare e multifilare devono restare documentate nelle rispettive sezioni.

## Procedura base

1. Creare un nuovo progetto con le informazioni principali della commessa.
2. Scegliere il cartiglio master.
3. Inserire il numero di fogli necessario.
4. Lasciare fogli liberi per pagine standard e documentali.
5. Inserire i blocchi standard come riferimenti DWG, non come blocchi semplici.

## Pagine standard consigliate

| Foglio | Contenuto |
|---|---|
| 1 | Dati cliente e dati aziendali |
| 2 | Disposizioni o informazioni di sicurezza |
| 3 | Targa quadro e marcatura |

## Inserimento pagine standard

Le pagine standard devono essere inserite come riferimento DWG.

Procedura:

1. Aprire un foglio libero.
2. Usare la funzione di inserimento riferimento DWG.
3. Selezionare il file DWG della pagina standard.
4. Usare un percorso controllato.
5. Posizionare il riferimento nel foglio.
6. Verificare che il collegamento resti valido dopo riapertura.

## Legenda fogli

Per inserire la lista dei fogli:

1. Aprire la funzione legenda fogli.
2. Generare la tabella.
3. Inserirla in un foglio dedicato.
4. Rigenerarla quando la struttura fogli cambia.

## Checklist template

Prima di usare un template come base:

- cartiglio verificato;
- pagine standard inserite;
- immagini e riferimenti validi;
- legenda fogli presente;
- fogli liberi disponibili;
- progetto salvato come base pulita.
