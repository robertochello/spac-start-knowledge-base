# Known Issues

Questa sezione raccoglie problemi noti, sintomi ricorrenti e procedure di diagnosi.

## Issues disponibili

| Issue | Sintomo |
|---|---|
| [Pin non agganciato](pin-not-snapping.md) | Il filo non si collega al pin del simbolo |
| [Riferimento immagine mancante](missing-image-reference.md) | Logo o immagine non visibile nel cartiglio |
| [Cross-reference obsoleto](obsolete-cross-reference.md) | Rimando verso posizione non più valida |
| [DbCables versione non congruente](dbcables-version-mismatch.md) | Avviso di versione database non congruente dopo sostituzione |

## Regola

Ogni known issue deve indicare:

- sintomo;
- causa probabile;
- diagnosi;
- soluzione;
- prevenzione.
