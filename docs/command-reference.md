# Command Reference

Riferimento operativo dei comandi e delle funzioni citate nella knowledge base.

!!! warning "Nota"
    I comandi possono variare in base ad ambiente, versione, configurazione e profilo caricato. Annotare sempre eventuali differenze osservate.

## Funzioni citate

| Area | Uso |
|---|---|
| Gestione menu | Ripristino o gestione dei menu CAD/SPAC |
| Personalizzazione interfaccia | Creazione shortcut e comandi personalizzati |
| Libreria simboli | Apertura della libreria simboli SPAC |
| Riferimenti | Gestione rimandi e cross-reference |
| Morsetti | Inserimento e configurazione morsetti |
| Cartigli | Gestione pagine standard e cartigli |

## Uso consigliato

- Documentare la funzione solo se è stata testata.
- Indicare il contesto in cui è stata usata.
- Evitare macro non documentate o non ripetibili.
- Collegare ogni funzione a un playbook o troubleshooting.

## Registro comandi

Quando un comando viene consolidato, documentarlo con:

- nome comando;
- area funzionale;
- quando usarlo;
- prerequisiti;
- esito atteso;
- problemi noti.
