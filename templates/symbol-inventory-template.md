# Template inventario simboli custom

Questo template definisce la struttura consigliata per mantenere un inventario dei simboli custom SPAC.

Il file operativo può essere mantenuto anche in formato Excel.

Nome consigliato:

```text
SPAC_Custom_Simboli_Convenzione.xlsx
```

## Campi consigliati

- ID progressivo
- Nome simbolo
- Categoria funzionale
- Descrizione sintetica
- Tipo simbolo
- Valore PRES se presente
- Tipo di pinatura
- Attributi principali
- Materiale associabile
- Stato test inserimento
- Stato test pinatura
- Stato generale
- Note operative

## Stati consigliati

- Testato
- Da verificare
- In revisione
- Deprecato

## Regole operative

- Evitare simboli duplicati con nomi simili.
- Aggiornare lo stato dopo ogni test.
- Non inserire dati sensibili se il repository è pubblico.
- Annotare sempre eventuali limitazioni del simbolo.
- Collegare il simbolo alla relativa procedura, se esiste.
